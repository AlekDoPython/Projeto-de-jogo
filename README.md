# Projeto-de-jogo
Projeto do jogo "Aero shield" estilo space invaders

O jogo consiste em defender uma civilização de ataques aéreos inimigos estilo space invaders pilotando um avião que atira constantemente para frente, onde ao longo do percurso você vai ficando mais forte junto com os inimigos. Seu objetivo é completar todas as fases de diferentes dificuldades com infinitas tentativas caso perca.
